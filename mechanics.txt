PART 4: SPREAD MECHANICS
================================================================================

TICK STRUCTURE (500ms intervals):
1. Spread Phase - Viruses expand to adjacent cells
2. Combat Phase - Adjacent enemies fight
3. Infestation Phase - Mutation-based conversion
4. Regeneration Phase - HP recovery (if using HP system)

SPREAD ALGORITHM:

private spreadVirus(
  grid: number[],
  x: number,
  y: number,
  virusType: number,
  width: number,
  height: number
): void {
  // Get virus parameters
  const params = virusType === 1 ? this.paramsA : this.paramsB;

  // 8-directional neighbors (Moore neighborhood)
  const neighbors = [
    { dx: -1, dy: 0 },  // left
    { dx: 1, dy: 0 },   // right
    { dx: 0, dy: -1 },  // top
    { dx: 0, dy: 1 },   // bottom
    { dx: -1, dy: -1 }, // top-left
    { dx: 1, dy: -1 },  // top-right
    { dx: -1, dy: 1 },  // bottom-left
    { dx: 1, dy: 1 },   // bottom-right
  ];

  // BASE SPREAD CHANCE
  const baseSpreadChance = (params.speed + params.reproduction) / 20;

  // AGGRESSION BONUS (for enemy cells only)
  const aggressionBonus = params.aggression * 0.025;

  // SPREAD ATTEMPTS (based on Contagiousness)
  const spreadAttempts = 1 + Math.floor(params.contagiousness / 5);

  // VIRULENCE BONUS (additional attempts)
  const virulenceBonus = Math.floor(params.virulence / 4);

  const totalAttempts = spreadAttempts + virulenceBonus;

  for (let attempt = 0; attempt < totalAttempts; attempt++) {
    const neighbor = neighbors[Math.floor(Math.random() * neighbors.length)];
    const nx = x + neighbor.dx;
    const ny = y + neighbor.dy;

    // Check bounds
    if (nx < 0 || nx >= width || ny < 0 || ny >= height) continue;

    const nIdx = ny * width + nx;
    const neighborCell = grid[nIdx];

    // EMPTY CELL - basic spread
    if (neighborCell === 0) {
      if (Math.random() < baseSpreadChance) {
        grid[nIdx] = virusType;
      }
    }
    // ENEMY CELL - attack with possible infestation
    else if (neighborCell !== virusType) {
      const attackChance = baseSpreadChance + aggressionBonus;
      if (Math.random() < attackChance) {
        // Try infestation first (if Mutation >= 4)
        if (params.mutation >= 4 && Math.random() < 0.5) {
          const infested = this.attemptInfestation(...);
          if (!infested) {
            this.attackCell(grid, nIdx, virusType, neighborCell, params);
          }
        } else {
          this.attackCell(grid, nIdx, virusType, neighborCell, params);
        }
      }
    }
  }
}

SPREAD CHANCE FORMULA:

baseSpreadChance = (speed + reproduction) / 20
  - At 0/0: 0% base chance
  - At 10/10: 100% base chance (capped)
  - Typical (6/6): 60% chance

SPREAD ATTEMPTS:

attempts = 1 + floor(contagiousness / 5) + floor(virulence / 4)
  - At 0/0: 1 attempt
  - At 10/10: 1 + 2 + 2 = 5 attempts
  - Each attempt picks random neighbor

PART 5: COMBAT MECHANICS
================================================================================

COMBAT TRIGGER:
When a virus spreads to a cell adjacent to an enemy cell, combat occurs.

ATTACK VS DEFENSE FORMULA:

Attack Roll = (speed + reproduction) / 20 + (aggression × 0.025)
Defense Roll = (defense + resilience) / 20

Stealth Bonus = stealth × 0.03  (ignores defense)
Stealth Penetration = stealth / 12  (0-100% defense ignore)

Effective Defense = defense × (1 - stealthPenetration)
Final Defense Roll = (effectiveDefense + resilience) / 20

If Attack Roll > Defense Roll:
  → CELL CAPTURED!
  → Cell changes owner
  → New cell HP = 30 (if using HP system)

COMBAT CODE:

private attackCell(
  grid: number[],
  idx: number,
  attackerType: number,
  defenderType: number,
  attackerParams: VirusParams
): void {
  const defenderParams = defenderType === 1 ? this.paramsA : this.paramsB;

  // ATTACK ROLL
  const attackRoll = (attackerParams.speed + attackerParams.reproduction) / 20
                   + (attackerParams.aggression * 0.025);

  // DEFENSE ROLL (with stealth penetration)
  const stealthPenetration = attackerParams.stealth / 12;
  const effectiveDefense = defenderParams.defense * (1 - stealthPenetration);
  const defenseRoll = (effectiveDefense + defenderParams.resilience) / 20;

  // RESOLVE COMBAT
  if (attackRoll > defenseRoll) {
    // Capture successful
    grid[idx] = attackerType;
  }
  // Else: attack fails, cell remains defender's
}

COMBAT EXAMPLE:

Virus A (attacking):
  - Speed: 8, Reproduction: 6, Aggression: 7
  - Attack Roll = (8+6)/20 + (7×0.025) = 0.7 + 0.175 = 0.875

Virus B (defending):
  - Defense: 5, Resilience: 4, Stealth: 2
  - Stealth Penetration = 2/12 = 16.7%
  - Effective Defense = 5 × (1 - 0.167) = 4.17
  - Defense Roll = (4.17 + 4) / 20 = 0.408

Result: 0.875 > 0.408 → Virus A captures cell!

PART 6: INFESTATION SYSTEM
================================================================================

INFESTATION REQUIREMENT:
- Mutation ≥ 4 points to enable infestation attempts
- 50% chance to attempt infestation instead of direct attack

INFESTATION STAGES:
1. Hidden (0-30% progress): No symptoms, cell behaves normally
2. Visible (30-70% progress): Reduced defense, slight color change
3. Critical (70-100% progress): Spreads to neighbors, about to convert

INFESTATION PROGRESS:
- +8% per tick (if successful roll)
- Converts at 100%
- Can spread to adjacent cells of same type in Critical stage

INFESTATION CHANCE FORMULA:

Base Chance = 20%

Mutation Bonus = mutation × 4%  (max +48% at 12 points)
Contagiousness Bonus = contagiousness × 2%
Stealth Bonus = stealth × 3%  (ignores defense)
Virulence Bonus = virulence × 1.5%
Pressure Bonus = surroundPressure × 20%  (0-20%)

Intellect Resist = intellect × 3%
Defense Resist = effectiveDefense × 2%
Resilience Resist = resilience × 1.5%

Final Chance = Base + Mutation + Contagious + Stealth + Virulence + Pressure
               - Intellect - Defense - Resilience

Clamped to: 2% - 95%

INFESTATION CODE:

private calculateInfestationChance(
  attackerParams: VirusParams,
  defenderParams: VirusParams,
  surroundPressure: number
): number {
  const baseChance = 0.2;
  const mutationBonus = attackerParams.mutation * 0.04;
  const contagiousBonus = attackerParams.contagiousness * 0.02;
  const stealthBonus = attackerParams.stealth * 0.03;
  const virulenceBonus = attackerParams.virulence * 0.015;
  const pressureBonus = surroundPressure * 0.2;

  const stealthPenetration = attackerParams.stealth / 12;
  const effectiveDefense = defenderParams.defense * (1 - stealthPenetration);

  const intellectResist = defenderParams.intellect * 0.03;
  const defenseResist = effectiveDefense * 0.02;
  const resilienceResist = defenderParams.resilience * 0.015;

  const finalChance = baseChance + mutationBonus + contagiousBonus +
                      stealthBonus + virulenceBonus + pressureBonus -
                      intellectResist - defenseResist - resilienceResist;

  return Math.max(0.02, Math.min(0.95, finalChance));
}

SURROUND PRESSURE CALCULATION:

private calculateSurroundPressure(
  grid: number[],
  x: number,
  y: number,
  virusType: number
): { enemyCount: number; allyCount: number; pressureLevel: number } {
  let enemyCount = 0;
  let allyCount = 0;

  const neighbors = [
    { dx: -1, dy: 0 }, { dx: 1, dy: 0 },
    { dx: 0, dy: -1 }, { dx: 0, dy: 1 },
    { dx: -1, dy: -1 }, { dx: 1, dy: -1 },
    { dx: -1, dy: 1 }, { dx: 1, dy: 1 }
  ];

  for (const n of neighbors) {
    const nx = x + n.dx;
    const ny = y + n.dy;
    const neighborValue = grid[ny * width + nx];

    if (neighborValue === virusType) allyCount++;
    else if (neighborValue !== 0) enemyCount++;
  }

  const pressureLevel = enemyCount / 8;  // 0.0 to 1.0
  return { enemyCount, allyCount, pressureLevel };
}

PRESSURE THRESHOLDS:
- 0.0-0.25: Low pressure (0-2 enemies)
- 0.25-0.5: Medium pressure (3-4 enemies)
- 0.5-0.75: High pressure (5-6 enemies)
- 0.75-1.0: Critical pressure (7-8 enemies)

SURROUNDED CELL RESPONSES:

If pressureLevel > 0.5 (5+ enemies):

1. High Intellect (≥8): Emergency spread to empty neighbors
   - Attempts: 1 + floor(intellect / 4)
   - Spread chance: (intellect + mobility) / 24

2. High Mutation (≥8): Desperate conversion attempt
   - Target: Random adjacent enemy
   - Chance: (mutation / 12) × 0.6  (up to 60%)

3. High Defense+Resilience (≥12): Temporary defense bonus
   - Visual effect only (no mechanical bonus)

4. High Stealth (≥8): Reduced infestation chance
   - Infestation resistance bonus

VICTORY CHECK (every tick):

private checkWinCondition(): void {
  const totalCells = this.gridData.grid.length;
  let virusACount = 0;
  let virusBCount = 0;

  for (const cell of this.gridData.grid) {
    if (cell === 1) virusACount++;
    else if (cell === 2) virusBCount++;
  }

  const totalOccupied = virusACount + virusBCount;
  if (totalOccupied === 0) return;

  const virusAPercent = (virusACount / totalOccupied) * 100;
  const virusBPercent = (virusBCount / totalOccupied) * 100;

  // DOMINATION VICTORY (96% threshold)
  if (virusAPercent >= 96) {
    this.endBattle('A', 'domination');
  } else if (virusBPercent >= 96) {
    this.endBattle('B', 'domination');
  }

  // TIMEOUT VICTORY (1000 ticks)
  if (this.state.tick >= 1000) {
    const winner = virusACount > virusBCount ? 'A' : virusBCount > virusACount ? 'B' : 'draw';
    this.endBattle(winner, 'timeout');
  }

  // ELIMINATION VICTORY
  if (virusACount === 0 && virusBCount > 0) {
    this.endBattle('B', 'elimination');
  } else if (virusBCount === 0 && virusACount > 0) {
    this.endBattle('A', 'elimination');
  }
}

VICTORY TYPES:
1. Domination: Control ≥96% of occupied cells → Instant victory
2. Timeout: Most cells at tick 1000 → Leader wins
3. Elimination: Opponent has 0 cells → Last standing wins
4. Draw: Equal cells at timeout → Both lose (rare)

BATTLE DURATION:
- Tick interval: 500ms
- Max ticks: 1000
- Max time: 500 seconds (8 minutes 20 seconds)
- Average battle: 30-120 seconds

CLIENT-SERVER MODEL:
- Server: Authoritative simulation (validates all actions)
- Client: Prediction + interpolation (smooth visuals)

NETWORK MESSAGES (Client → Server):

   Purpose: Set virus configuration

2. toggleReady
   Data: { isReady: boolean }
   Purpose: Toggle player ready status

3. startBattleNow
   Data: {}
   Purpose: Request immediate battle start

NETWORK MESSAGES (Server → Client):

1. startCountdown
   Data: { vGrid: number[], width: number, height: number }
   Purpose: Start 3-2-1 countdown

2. virusTick
   Data: { tick: number, vGrid: number[] }
   Purpose: Battle grid update (2/sec)

3. virusBattleEnded
   Data: { winner: string, virusACount: number, virusBCount: number }
   Purpose: Battle ended, show results

SERVER ROOM LOGIC (Colyseus):

export class BattleRoom extends Room<RoomState> {
  private readonly TICK_RATE = 500; // ms per tick
  private readonly WIN_THRESHOLD = 0.96; // 96% domination

  onCreate(options: any) {
    this.setState(new RoomState());
    this.setSimulationInterval(() => this.battleTick(), this.TICK_RATE);
  }

  private battleTick(): void {
    this.processSpreadPhase();
    this.processCombatPhase();
    this.processInfestationPhase();
    this.checkWinConditions();
    this.broadcast('virusTick', { tick: this.state.tick, vGrid: this.state.vGrid });
  }
}
