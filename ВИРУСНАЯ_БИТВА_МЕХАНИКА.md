## 🎯 ПРОБЛЕМА

Кнопка **START BATTLE** нажимается, но **ничего не происходит**. 

**Причина:** BattleRenderer не отображает сетку битвы, потому что не подписан на обновления.

---

## 📋 ЧТО ДОЛЖНО ПРОИСХОДИТЬ

### 1. Игрок нажимает START BATTLE
```
[MainApp] ⚔️ START BATTLE button clicked!
[MainApp] Grid created (32x20), starting battle...
[MainApp] Battle started!
```

### 2. BattleManager создаёт сетку
```javascript
width = 32
height = 20
vGrid = [0, 0, 0, ..., 0]  // 640 клеток (все пустые)

// Вирус A (Красный) - слева
vGrid[324] = 1  // cell index = 10*32 + 2

// Вирус B (Синий) - справа  
vGrid[317] = 2  // cell index = 9*32 + 29
```

### 3. BattleManager запускает цикл распространения
```javascript
setInterval(() => {
  spreadTick();  // Каждые 500ms
}, 500);
```

### 4. Каждый тик:
- Вирусы распространяются на соседние клетки
- Происходят сражения между вирусами
- Обновляется сетка
- **BattleRenderer должен перерисовать сетку** ← ЭТОГО НЕ ПРОИСХОДИТ!

## 📊 АЛГОРИТМ РАСПРОСТРАНЕНИЯ

### spreadVirus() функция:

```typescript
function spreadVirus(grid, x, y, virusType, width, height):
  // Получить параметры вируса
  params = virusType === 1 ? paramsA : paramsB
  
  // Проверить 8 соседей
  for each neighbor (nx, ny):
    if grid[ny * width + nx] === 0:  // Пустая клетка
      // Шанс захвата = propagation * 0.1
      if random() < params.propagation * 0.1:
        grid[ny * width + nx] = virusType
        
    else if grid[ny * width + nx] !== virusType:  // Враг
      // Бой!
      attackerStrength = params.aggression + params.virulence
      defenderStrength = params.defense + params.resilience
      
      if attackerStrength > defenderStrength + random(0-10):
        // Атакующий победил - захватить клетку
        grid[ny * width + nx] = virusType
```
